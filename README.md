# PocketPet 🐾

A small Java-based virtual pet simulation. Created to show you my basic Java skills.

## Features

- Feed your pet
- Play games
- Manage energy and happiness
- Save progress (TODO)

## Technologies

- Java 21
- Object-oriented programming
- File persistence
